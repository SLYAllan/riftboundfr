## GRANDE FINALE — Vex (choco) vs Ezreal (bradykin) — Ezreal gagne 2-1
- **Ezreal control** : **Bewitching Spirit** (discard) + gold via **Plundering Poro** (conquer → gold) → spells cheap ; Wages of Pain / Bellows Breath / Deadly Flourish / Stupefy (removal) ; **Star-Crossed** + Fizz ; Watcher ; **The Academy**[?] (battlefield = double Gust pour peu de coût → removal de battlefield accélérée). 
- **Vex (choco)** : **Evelynn** (hidden, "3 kills d'affilée"), **Vex Apathetic** ("meilleure unité 4-coût du jeu" `[avis]` : deflect + stun les unités jouées + 4 might), **Tideturner** (move/draw), Stellacorn, **Discipline** (= MVP du matchup, sauve choco plusieurs fois), Charm, Sona, Baron Nashor, Fizz, Not So Fast, Gust, Pike ; **pas de Shadow** (joué sans). Vex = **tenir 1 battlefield + draw 1/tour**.

- **Verdict** : **Ezreal favori vs Vex** `[avis]` — **renvoyer la Vex à la main (Rebuke/Star-Crossed) reset son moteur de hold** ; mais Vex gagne si Discipline+Apathetic verrouillent un battlefield tôt.

## R1 — Pyke vs Azir (Azir gagne 2-0)
- **Azir (yellow, go-wide gear/sand soldiers)** : nouveau **Soul Sword** (gear 1-drop = +consistance pour les sand soldiers), Eye of Herald, BF Sword, Brutalizer, **Arise**, **Desert's Call** (repeat → remplit la back-line), **Hall of Legends** (conquer → 1 énergie ready Azir → encore un sand soldier ; "Azir ne manque jamais de pression"). **Sharkling**[?] (Set 3 : 3/4 Assault, accelerate). Mécanique : **1 équipement joué → coche le bloc ; si Azir untap, pas besoin d'un autre gear pour un 2e sand soldier**.
- **Pyke (red/purple, self-bounce/discard)** : **Bewitching Spirit** (discard, bounce+replay → vide la main adverse), **Death from Below** (signature kill, **rejouable si la cible ≤3 might**), Falling Star, red Pike champion (accelerate via 1 power → +2 + ready). Plan = ne **pas laisser l'adversaire jouer de cartes**.
- **Verdict** : **Azir favori vs Pyke** `[avis]` — le plan discard de Pyke est **faible vs un deck qui joue depuis le BOARD pas la main** (Azir = aggro-midrange "all gas no breaks") ; Pyke trop fixé sur le discard, ne développe pas. (Pyke shine vs Aurora/decks qui vont long, pas vs Azir.)

### Game bonus — MF Aurora vs Azir (MF Aurora gagne)

## R2 — Volibear "Miracle Dragons" vs LeBlanc (Volibear gagne 2-0) ⭐ ARCHÉTYPE NOUVEAU
- **Volibear Miracle Dragons** (Storm/Dragons, archétype combo non couvert ailleurs) : moteur = **Gem Dragon** (chaque dragon joué → untap des runes) + **Herald of Scales** (les dragons coûtent **-2 énergie**) + **K-Dragon/Khadrigan**[?] (on play → draw ~4-9 cartes). Avec **3 Gem Dragon + 3 Herald of Scales** : tout à **-6 énergie + untap 6/dragon** → **"26 énergie flottante", draw quasi tout le deck = tour Miracle**. Autres : **Dune Drake** (7 might si unités ready), Blazing Scorcher, Dragon Sage, un **dragon 12-drop** (coûte 8, untap 4). Tech : **Sabotage** (strip la main de LeBlanc, recommençable chaque tour), Confront (enter ready), Vi (sacrifice pour draw).
- **vs Blue LeBlanc (hybride sprite-aggro !)** : build unique = **Lillia Fae Fawn** (accelerate, laisse un sprite), **Smoke and Mirrors**, **Petal Pixie** (+1 might par unité temporaire au battlefield → 12+ might), Mirror Image (reflection 8 might, pas l'on-play), Sprite Fountain, Honest Broker, LeBlanc Fragmented (Assault → 4 might en attaque). = LeBlanc **blue** orientée sprites (≠ la LeBlanc yellow Karthus de pass4/5).
- **Déroulé** : LeBlanc start très rapide (sprites + Lillia Fae Fawn T2, board énorme), MAIS Volibear stabilise (Falling Star/Challenge/Blazing Scorcher clear) puis lance le moteur Miracle → **draw infini + mana infinie** → submerge. Sigil of the Storm (LeBlanc battlefield) ralentit un peu Voli (de-ramp).
- **Verdict** : **Volibear Miracle Dragons bat LeBlanc** `[avis]` — out-value total une fois le moteur en ligne ; la pression sprite ultra-rapide ne suffit pas. ⚠️ **Nouvel archétype combo à surveiller** (Gem Dragon + Herald of Scales = clé).

## R3 — Lillia vs Darius (Lillia gagne 2-0)
- **Lillia (sprites aggro)** : point Poro, **Sprite Queen**, Sprite Mother, **Sprite Burst** (2 sprites), **Smoke and Mirrors**, Bashful Bloom, **Abandoned Hall** (+1 might/sort), **Thousand-Tailed Watcher**, Phaethon[?]. Plan = **double conquer chaque tour** (high-risk/high-reward).
- **Darius (Fury+Order, Phoenix/go-wide)** : **Immortal Phoenix** (rejoue du trash en tuant une unité au sort), Noxus Hopeful, **Shadows Call** (draw 4 + donne temporary), Battering Ram, **Undying Legion** (Legion : rejoue du discard pour 3+1power), Deathgrip, Sacrifice, **Ferrous Forerunner** ("carte la plus jouée du Set 2", très sticky mais inerte tant qu'elle ne meurt pas `[avis]`), Falling Star, Seal of Rage.
- **Déroulé** : Darius **rate son play T1** (pas de rune rouge) → puni ; Lillia consistante double-conquer ; quand Darius overcommit ses runes pour clear, il se laisse ouvert. Note caster `[avis]` : **Master Yi bon vs Vex/LeBlanc via Ruin Runner** (ils galèrent face au camel untargetable).
- **Verdict** : **Lillia favorisée vs Darius** (consistance + double conquer ; Darius punit si Lillia overcommit, mais peine sinon). Ruling rappelé : **Defy sur Deathgrip/Sacrifice ne sauve pas l'unité** (le kill = coût).

## R4 — LeBlanc vs Vex (Vex gagne 2-1)
- **LeBlanc (yellow Karthus)** : Ruined Rex, Honest Broker, Watchful Sentry, Lonely Poro, Glasc Mixologist, Abandon, Call the Weak, Hidden Blade — **MAIS n'a jamais tiré ses Karthus** (×3 en deck) → "joue bien sans sa pièce maîtresse". **Unchecked Power = la réponse anti-Vex** (clear un battlefield 12-might → reset le hold).
- **Vex** : Overzealous Fan, Evelynn, **Mutated Mouser** (débat vs Lonely Poro : Mouser = 5-might défensif T1-2 plus solide), Vex Apathetic, Sona, **Grove of the God Willow** (hold → draw 3), **Boots of Swiftness sur Vex** (tech novelle de "Gray" : ganking → bouge gauche-droite au lieu de retreat), Amateur Recital, Star-Crossed, Not So Fast ×2.
- **Déroulé** : **LeBlanc ne gagne QUE la game où elle joue first** → caster `[avis]` : **"going first > going second" décide ce matchup** (pas que Vex > LeBlanc). Vex grind via hold + draw (Grove). LeBlanc ferme via Unchecked Power quand elle l'a.
- **Verdict** : serré, **l'ordre de jeu décide** ; le hold de Vex est favori MAIS **Unchecked Power (LeBlanc) reset tout**. (Cohérent pass8 : Unchecked Power = réponse aux hold decks.)

## Méta-takeaways Win-A-Box
- **Vainqueur = Ezreal** (control, bat Vex en finale). **Ezreal = anti-Vex** (renvoie la Vex à la main → reset le hold).
- **Volibear Miracle Dragons** = archétype combo émergent (Gem Dragon + Herald of Scales + K-Dragon = draw/mana infinie) → bat LeBlanc.
- **Azir** = aggro-midrange "all gas" (Hall of Legends + Soul Sword), bat les decks de discard (Pyke) ; **MF Aurora** le reset (Bullet Time + Flurry of Blades + Elder).
- **Aurora = meilleur deck game 1, plus faible games 2-3** (prévisible).
- **Unchecked Power / Downwell = la réponse obligatoire aux hold decks** (Vex/Yi/MF) pour Diana & co.
- **Ferrous Forerunner** = toujours la carte Set 2 la plus jouée (sticky, ban-watch latent).
