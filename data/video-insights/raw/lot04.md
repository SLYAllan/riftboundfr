## UNLEASHED
- **Rek'Sai vs LeBlanc (Utrecht R8 — Rek'Sai 2-0)** : matchup très favori Rek'Sai (LeBlanc joue 1 unité/tour → la mauvaise défense de Rek'Sai ne se manifeste pas). Falling Star nettoie les petites unités LeBlanc (Soaring Scout, LeBlanc Fragmented). Lignes : empiler des unités tôt + Undertitan (anthem + 2 énergie au reveal). Double conquête via Kai'Sa Survivor + Zaun Warrens + légende Rek'Sai. Tech : Forbidden Waste G2/3 (durcit les conquêtes vs decks à peu d'unités).
- **Prismaticism (Annie) vs Diana (Utrecht R4 — Annie 2-0)** : liste Annie « propre » (triple Noxus Hopeful/Kai'Sa/Stack Deck, Traveling Merchant, Flash, Ferrous Forerunner). 1 Hard Bargain + 1 Abandoned (versatilité). Pas de removal direct (maximise le hero power d'Annie). Diana Jewel : Frigid Jewel pompe Hwei ; double Stupefy + Jewel au tour adverse. Annie joue le double conquer plutôt que le hold.
- **Prismaticism (Annie) vs Azir (Hartford R13)** : Annie prend G1. Tournant : double Long Sword (Azir n'a pas de gear removal main → pas de réponse). Star-Crossed « rebuke des temps modernes ». Thermo Beam dévastateur vs Azir gear-heavy (wipe 7-8 gears). Vex Apathetic = « carte du format » (stoppe Arise + Vi). Back Off annule Long Sword. G2 (Aurora vs Diana) : Baron Nashor finisher Aurora quasi-imbattable pour Diana (seule sortie = Unchecked Power, slow). Interaction Vex + Aurora : l'unité jouée par Aurora en fin de tour entre stun, non retiré au cleanup.
- **Darius vs Irelia (Xi'an R5 — Darius gagne)** : matchup penche Irelia mid-game mais Darius gagne par tempo précoce. Tech : Salvage main (bait la GA puis tue Irelia), Jinn[Order] (+4 might / 4 dmg si pas de conquer → 8-12 might mobile), Cull the Weak. Abandoned Hall énorme pour Irelia (+1 might/spell, +2 si choisie).
- **Kai'Sa miroir (Shenzhen $30K Day2 R8)** : double Immortal Phoenix gagne le miroir (revient à chaque kill, épuise les removal). Triple Progress Day (draw 12+), Time Warp, double Void Gate.
- **Diana vs Draven (Tournament 2 — Draven 2-0)** : Draven copie le plan Vex Apathetic (purple partagé, draw sur victoire de combat) + removal red dur (Falling Star, Piercing Light). Net-new : Bone Skewer (force l'adversaire à jouer une unité + stun), Eclipse (-4 might min, sans plancher, + predict), Star-Crossed (commun, « carte préférée set 3 »). G3 : Dragonsoul Sage[?] (2-drop ramp) libère Volibear de la dépendance Dazzling Aurora ; Leona montée via stun (Back Off).
- **Diana vs Draven (Tournament 14 — Draven 2-1)** : Falling Star = boogeyman anti-Diana. Aspirant's Climb G2 going second. Méta anti-Aurora set 3 : Turn to Dust, Star-Crossed (renvoie l'Elder Dragon en main), Unchecked Power (12 dmg AOE side blue), Not So Fast ; Sabotage/Mindsplitter contournent.
- **Révélation Yeti Brawler** (Fury, 6é/0p/6 might) : conquer avec 3+ dégâts excédentaires → 2 gold tokens. Combo Vi.
