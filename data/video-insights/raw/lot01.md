## SET — UNLEASHED

### Vex vs LeBlanc (Set 3, finale Unleashed)
- LeBlanc gagne 2-0 (pilote « Nurov »). Plan LeBlanc = surcharge de removal + copies via la capacité de Légende (défausser Tactical Retreat pour copier Watchful Sentry, double tirage).
- **Cull the Weak**[« Call the Week »] = carte clé anti-Vex : élimine le Vex Apathetic (champion) à répétition. Triple Cull the Weak en game 2 (purple Vex puis green Vex puis Ruin Runner[« Vyomaw »] tous éliminés). Une fois le champion Vex retiré, le plan Vex s'effondre (deck = surtout sorts + défense).
- Piège Vex : mauvais séquencement de Zhonya's Hourglass + Overzealous Fan (anti-synergie). Mieux : poser Vex au tour précédent sous Targon's Peak et garder le Zhonya pour protéger le champion d'un Cull the Weak.
- Réponses Vex sur le papier : Defy (contre Cull the Weak), Charm (tirer un Karthus vers son champ pour le tuer tôt). Pas assemblé.
- Ligne LeBlanc : Star-Crossed (bounce une unité alliée + une adverse) contré en réaction par sacrifice + Hidden Blade → double death knell (Ruined Rex ×2 → -4 + -4). Black Rose Dignitary (+1 assault avant mort, channel rune). Forbidding Waste (battlefield Set 3 : unité qui défend seule = -2).

### Fiora vs Draven (Unleashed Tournament 2)
- Draven gagne 2-1. Draven mid-range, MVP = Ferrous Forerunner (6 might + trois mechs 3-might au death knell ; impossible à gérer sans rebuke en deck non-chaos).
- Draven utilise Vex Apathetic (4 might, 0 power, deflect) + Bone Skewer (hand rip ciblé) + Abandon (recur, card draw).
- Plan Fiora : monter Fiora (Set 1, deflect/ganking/shield) mighty via Sett/BF Sword/Doran's Blade, channel runes, Challenge pour retirer, Call to Glory pour ready. Faiblesse : ne tient pas les battlefields.
- Pièges combat : les triggers attack/defend (Overzealous Fan) ne se déclenchent qu'au début du showdown — Ride the Wind qui renvoie une unité dans le MÊME showdown ne re-déclenche pas. Ligne Draven : Ride the Wind en réaction sur le ready de la Légende = win de combat « gratuit ».

### Généralités Unleashed
- Brynhir Thundersong[« Bring Your Thunder Song »] : carte méta-cassante Set 3 (1$→5$). Empêche l'adversaire de jouer des cartes. Va sur le chain → réactible avant résolution.

## SET — SPIRITFORGED

### Irelia mirror (défini par le deck)
- Carte centrale Defiant Dance. Stellacorn Herder = MVP card-draw (10+ cartes, demandes de ban). Aurelia/Irelia Fervent = reine : qui perd sa reine en premier perd quasi la game.
- Tech : Flash jouable en réaction au ready/awaken step de la Légende Fervent. Double Flash mainboard justifié. Side : Adaptatron (anti-gear), Vex (mirror-breaker), Edge of Night (équipement caché), Doran's Ring. Charm pour pousser le Fervent adverse + le tuer en showdown.

### Irelia vs Draven (Cash Cup GF)
- Irelia gagne via le card advantage de Stellacorn ; Reaver's Row favorise souvent Irelia (chosen → +1, quasi inretirable). Piège Draven : oublier que Reaver's Row donne +1 à Irelia. Draven anti-Irelia : Falling Stars/Piercing Light (tue Stellacorn tôt), double Fight or Flight, Brynhir Thundersong, Tideturner caché.

### Ezreal vs Draven (Cash Cup 1K GF — Spiritforged)
- Draven gagne 2-1. Ezreal = control/removal (Bellows Breath ×3, Singularity, Fizz loop via Pack of Wonders, Mindsplitter, Wages of Pain, Frigid Touch, Rebuke). Combo MF/Ezreal : Pack of Wonders + Treasure Trove → bounce, ramp + draw. Draven gagnant : Thermo Beam très tôt (T2-T3, détruit seals/gear), Ferrous Forerunner, tirages gratuits via la Légende, Rebuke près du corps.

### Ezreal vs Viktor (prison bleu, Spiritforged T10)
- Ezreal gagne 2-1. Viktor bleu prison = oops-all-removal + tokens. Pièce maîtresse Vanguard Armory (3 recruit tokens + flux continu). Renata rend les tokens accelerated. Réponse Ezreal : Rocket Barrage répétable (tue les Armory), Down Well (tue tous les tokens), Factory Recall, Hard Bargain. Vex côté Ezreal rend Bellows Breath repeated ultra-cheap.

### Ezreal vs MF Aurora (Bologna Regional GF — Spiritforged)
- Alan ZQ (Ezreal) gagne 2-0 → premier champion régional occidental Spiritforged. MF Aurora = 5 unités, Dazzling Aurora + Catalyst of Aeons, Last Rites, Volibear (18+ might avec Punch First), Mindsplitter, double Hard Bargain, Sabotage, Invert Timelines. Faiblesse : 2 tours de valeur seulement, peu de runes pour les gros bears. Down Well/Unchecked Power = anti-Aurora idéal.

### Lucian vs Kai'Sa (Spiritforged T13, post-bans)
- Plan Lucian : équiper TÔT pour passer au-dessus des seuils de removal Kai'Sa. Lucian n'a quasi aucune carte reaction-speed. Ruin Runner important. Kai'Sa : Falling Star, Stupefy+Hextech Ray, Singularity, Blood Rush sur Kai'Sa.

### Viktor vs Kai'Sa (Spiritforged T8/T12 post-bans)
- Viktor unit-deck brille rarement. Ferrous Forerunner (12 might pour 6+1). Jace + Vanguard Armory combo. Kai'Sa gagne via removal + Time Warp final. Glasc Mixologist = bonne réponse au removal Kai'Sa.

### Annie vs Kai'Sa (Cash Cup GF, R&R)
- Kai'Sa gagne 2-1. Annie très agressif : Sneaky Deckhand MVP, Stubborn Annie (stack deck), Vi + Ride the Wind = win-con, Bane (side). Kai'Sa : Falling Star (Void Gate), Thousand-Tailed Watcher (-3 might board-wide), Darius, Singularity, Void Seeker.

### Azir vs Annie (Nanjing Regional GF — Spiritforged)
- Annie (EDG/AI) gagne 2-0 (première Annie championne régionale chinoise). Azir = tokens/equipment (Sand Soldiers, Eye of the Herald, BF Sword, Brutalizer, Arise, Weapon Master). Faiblesse : mauvaise gestion de main. Cull the Weak phare anti-Azir. Annie side gagnant : triple Rengar (tank), Mindsplitter, Ferrous Forerunner ; Hidden Blade sur sa propre unité = draw 3.

### Azir vs Master Yi (Lille Regional GF — Spiritforged)
- Cast partiel. Retenu : discipline sur les mis-triggers en compétitif (Thousand-Tailed Watcher -3 doit être annoncé).

### Fiora vs Draven — dominance Draven sur les régionaux Spiritforged
- Quatre régionaux → Draven champion à chaque fois. (1) Brynhir Thundersong ferme les games. (2) Ferrous Forerunner + Mindsplitter MVP. (3) Draven qui construit ses gold tokens (Treasure Hunter) garde l'avantage. Fiora : équipements en OFFENSE > défense (double-dip BF Sword via Weapon Master/Pit Rookie, Sett Brawler, Call to Glory, Punch First, Spectral Matron, Death Claw). Erreur : garder les Punch First en défense.

### Kai'Sa vs Ezreal (Dalian Regional GF — Spiritforged)
- Kai'Sa gagne. Retournement G2 : double Blue Horn (deflect, +1 might/gear, 14-24 might) = quasi-inretirable. Leçon : grosses unités deflect = meilleur anti-Kai'Sa late game.
