## SPIRITFORGED (régionaux chinois — Fuzhou, Chengdu, Nanjing, Dalian, Shenzhen)
- **Annie vs Aurelia (Fuzhou — Annie 2-0)** : Annie mid-range good stuff (Tide Turner, Treasure Hunter, Sneaky Deckhand, Ferrous Forerunner, Draven). Switcheroo + Hard Bargain en boucle. Sur le Dreaming Tree, Annie reste rarement tapée out (avantage). GA sur Aurelia neutralise les kill-spells.
- **Fiora (Baited Hook) vs Draven (Chengdu — Fiora 2-1)** : surprise (Baited Hook jusqu'en top 8). Trifarian War Camp trivialise les seuils Mighty. Sett Brawler (ready la Fiora via legend). Ne pas conquérir sur Reaver's Row si tapé out. G3 : BF Sword s'attache, l'unité meurt (Baited Hook), la BF Sword revient → réattache → 33 might.
- **Irelia vs Kai'Sa (Nanjing)** : très défavorable à Kai'Sa (Fervent a Deflect = chaque removal coûte le deflect → économie de runes effondrée). Renversement final Kai'Sa 2-1 (Pondering Poro paie les coûts deflect + Time Warp/Watcher + Thermo Beam).
- **Jax vs Draven (Dalian — Draven 2-1)** : Jax impressionnant (Sea Monkey, First Mate, Brutalizer, Aphelios, Jax Unmatched = quick draw sur tous les gears). Mindsplitter dead-draw plusieurs tours (rien à conquérir).
- **Ezreal (Pit Crew) — star du top cut** : combo Pit Crew + Call + Boots of Swiftness (ready à chaque gear + gold au conquer + ganking double-conquer puis recall). Finitions : Bellows Breath + Watcher, Arcane Shift + Watcher. Faiblesse : Falling Star sur le Pit Crew effondre le plan. **Chute souvent en top cut face à Aurelia.**
- **Sivir (Miracle) vs Aurelia (Dalian — Sivir)** : On the Hunt[?] (ready toutes les unités, contourne Defy). Sneaky Deckhand performe dans Irelia/Aurelia. Challenge anti-Irelia (tue le Fervent dès sortie).
- **Viktor (token/decree)** : matchup écrasant vs les decks ramp (boucle Vanguard Armory + Veiled Temple = ~12 recruits). Imperial Decree + Bellows Breath = wipe. MAIS perd vs Set quand le Ruin Runner sort (intouchable, aucune réponse).
- **Volibear Dragons vs Sivir Miracle (T10 — Sivir 2-1)** : Volibear Dragons SANS Aurora (Herald of the Scales = dragons -2, Cattergrin[?] draw massif, Storm Bringer signature). Minotaur (anti-retour en base). Sivir mid-range avec Yone (sous-estimé : Ride the Wind → conquer vide + 7 dmg backline + recall).

## UNLEASHED

Punch First sur le camel = protection absolue. Draven : Against All Odds main, double Edge of Night, Switcheroo (catastrophe pour Lee Sin). Valmont's Lair bon anti-Draven.
- **Ezreal Pit Crew (miroir) vs Lux (Fuzhou)** : Lux très faible (pas de removal early, pas de conquer ; legend draw 5 à réaction = sa seule force). Écrasée par Aurelia 8-0/5-0.
- **Ezreal vs Azir (top 64 Fuzhou — Azir)** : Azir go-wide (équipe ses sand soldiers via legend → hors range Bellows). Valmont's Lair side. Ezreal : Watcher + Bellows répété + Void Gate. Sacred Shears (death-knell draw aux sand soldiers).
- **Master Yi vs Draven (top 64 Fuzhou — Draven 2-0)** : Yi a un matchup correct (Ruin Runner intouchable + Valmont's Lair). Sort le camel trop tard. Twonk[?] (stun) répond aux gros buffs Draven.
