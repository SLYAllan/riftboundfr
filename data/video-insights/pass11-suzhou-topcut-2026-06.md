## FINALE — Master Yi vs Irelia (Master Yi gagne, 3 games)
**Le match-clé du tournoi**, très haut niveau, decklists ouvertes.
- **Game 1** : Irelia (higher seed) choisit de jouer first sur **Targon's Peak** (conquer → ready 2 runes = casser une défense puis garder des runes au tour adverse). Master Yi tient avec **Rengar** (ambush, défend pour 8 même joué en réaction) + **Stellacorn Herder** (draw on move) + Star Spring (semi-gank via First Mate). Point-clé de matchup `[avis]` : **le +2 might de Master Yi en défense seul** fait que **Yi investit BEAUCOUP moins de pumps qu'Irelia** ; la game se joue sur "qui gère le mieux ses ressources". Irelia doit dépenser Boots+Discipline+Defy juste pour passer une attaque → tapée out → punie par **Ride the Wind** (Scuttle 0-might envoyé puis ride). Yi ferme sur un push où Irelia, exposée, ne trouve pas le pump. **Yi 1-0.**
- **Game 2** : Master Yi **sideboard agressif anti-Irelia** = rentre **3 Akshan ("action") + 3 Sabotage + 2 Not So Fast**, sort tous ses Vilemaw/Valmar[?]. Plan = **"Irelia trap"** : (1) sabotage rippe les buffs/gear d'Irelia, (2) **Akshan** retire à action-speed sa protection (Zhonya's/Boots) une fois posée, (3) **Charm** l'Irelia dans un Vilemaw. Même un Akshan **Not-So-Fast'd** vaut le coup (un Defy de moins). Irelia tient quand même grâce à une main pleine de buffs + Abandoned Hall (**+2 might par sort joué** sur Irelia, pas +1) + Star-Crossed (invalide un Punch First en renvoyant l'unité). Ruling vu : on garde le contrôle d'un battlefield tant qu'un truc est sur la chain → Zhonya's sur Lonely Poro reste utilisable au death-knell. **Irelia 1-1** (ferme via Defiant Dance + Stellacorn + Star-Crossed).
- **Game 3** : Battlefields **Vilemaw's Lair** (Irelia coincée dedans sans Boots) + **Abandoned Hall**. First Mate posé tôt = défenseur 5-might qui squatte Vilemaw's Lair et **taxe les runes** d'Irelia tour après tour. Erreur identifiée par les casters : l'Irelia **renvoie son Rengar à la main** (au lieu du Yi) → "a sans doute décidé la game". Yi ferme avec **Vilemaw/Valmar (réaction = +8 might, type White Flame)** + Punch First (+ le +1 d'Abandoned Hall sur l'attaque Ride-the-Wind) → 13 might. **Master Yi champion.**
- **Verdict matchup** : **Master Yi favori** `[avis]`. Le +2-en-défense-seul rend Yi bien plus rune-efficace ; le sideboard sabotage/Akshan/Not-So-Fast + Charm-dans-Vilemaw ("Irelia trap") est le plan gagnant. Irelia gagne si elle garde la main pleine de buffs (Abandoned Hall = moteur).

## TOP 4 — Master Yi vs Sivir (Aurora) (Master Yi avance)
- Sivir joue les classiques Aurora : **Aspirant's Climb**, Sabotage (génère un **gold** via la légende → seule Aurora qui sabote sans perdre le tempo), Catalyst, Treasure Trove, **Elder Dragon ×3**, **Mind Splitter ×3**, **Possession** (vole une unité ennemie), Akshan, Heedless Resurrection, Last Rites, Stack Deck ×3 / Lunar Boon ×3.
- Master Yi (Trinity Force[?] battlefield, Star Tip Peak, Ruin Runner untargetable, Tasty Faefolk, Scuttle, Rengar, **Vilemaw/Valmar**[?], Punch First). Plan anti-Aurora `[avis]` = **outpace early** (Sigil/Star Tip Peak = 1 rune en plus/tour) ou **voler l'Aurora à l'Akshan**.
- Game-clé : Master Yi à **7-1**, MAIS Aurora revient quand même (Elder Dragon untargetable + Mind Splitters scorent depuis Valmont). Yi joue **Akshan** → **vole le Dazzling Aurora** (= "game-changing"). MAIS Sivir réplique **Possession** → re-vole l'Akshan, reprend l'Aurora. Citation casters : **"contre Aurora c'est toujours du temps emprunté"** ; "just counter it" est un mythe (il faut tirer les counters AVANT, jamais garanti). Master Yi finit par fermer (Vilemaw + Punch First) mais "sweat" total.
- **Verdict** : **Aurora oppressante même perdante aux points** ; Master Yi gagne via outpace + Akshan, mais Possession est le contre-au-contre. Aurora = consistance Sivir > MF (le gold permet sabotage + survie).

## TOP 8 — Irelia vs Sivir (Aurora) (Irelia gagne)
- **Irelia main-deck Adaptatron** = la grosse tech `[avis]` : 1-of en main, anti-Aurora/gear (ne peut pas être sabotée comme une **unité**, hard à gérer), tiré et joué dès game 1. Aussi : **Vex Apathetic**, **Baron Nashor**, **Heart of Dark Ice** (+3-4 might récurrent, ready), Defiant Dance, Boots, Guardian Angel, Defy/Not So Fast, Star-Crossed, Stellacorn Herder, Sunken Temple.
- Lignes vues : Irelia ne sort sa championne **que quand nécessaire** (Deflect + tools = solo carry) ; Heart of Dark Ice = "sort gratuit" chaque tour (ready une unité sans dépenser de sort) ; Star-Crossed sauve/renvoie ; **Factory Recall** en SB (band-aid temporaire vs Aurora). Sivir tente Aurora→Elder mais l'**Adaptatron + le hold d'Irelia** étouffent l'install.
- **Verdict** : **Irelia favorisée vs Aurora** grâce à Adaptatron main-deck + Vex + Baron + hold. (Confirme pass5 : Irelia "consistante", gros tournoi.)

## TOP 16 — Ezreal vs Diana (Ezreal gagne 2-0)
- **Ezreal control** (Mind+Chaos) : **Deadly Flourish** = MVP `[avis]` (removal 4-cost back-line + gold ; rend le "going first" bien meilleur, ~6-9 outs au 1er point ; tempo-swing énorme sur le champion T3 de Diana), **Star-Crossed** ("peut-être la meilleure carte du deck/de Riftbound" `[avis]`), Bewitching Spirit (discard, brille en late pas en early), **Acceptable Losses** (anti-gear, choisi comme Cull the Weak ; rentré vs Diana qui joue des seals), Watcher+Bellows, Fizz/Arcane Shift (rejoue), Mind Splitter (le caster le trouve **surévalué** vs decks à gros draw), Ezreal Prodigy, double Seal. Pack of Wonders : **1 seul** suffit `[avis]` (sinon trop de cartes mortes).
- Diana : Hwei (cible discard/removal), Moonfall (×2-3, signature), Vex Apathetic, Ride the Wind, Frigid Jewel, Diana Lunari (predict→draw sorts).
- Déroulé : Game 1 Ezreal **revient de 7-1** (Diana high-roll triple Moonfall/Watcher mais Ezreal stabilise via removal + Bewitching late). Game 2 Ezreal contrôle d'entrée (Deadly Flourish + Star-Crossed + Acceptable Losses sur les seals).
- **Rulings notés** : (a) **Fizz override le banish d'Arcane Shift** → Arcane Shift rejoué au Fizz est **recyclé** (pas banni). (b) **Flash sauve une unité d'Elder Dragon** (si seules cibles au battlefield). (c) **China garde l'ancienne règle "missed trigger"** (si tu channel/draw et passes, tu perds le point d'Arena's Greatest — plus punitif que l'Occident). (d) débat "rewind" : la Chine autorise reprendre tant que la game-state n'a pas changé.
- **Verdict** : **Ezreal favori vs Diana** `[avis]` — removal massive + combat tricks de Diana inefficaces (Ezreal ne commit pas d'unités early) + Deadly Flourish gère la back-line.

## TOP 32 — Lillia vs Rek'Sai (Lillia gagne 2-0)
- **Lillia (sprites, aggro)** : decklist très "0-to-100" (masse de 2-3 drops + triple Unchecked Power/Singularity/double Thousand-Tailed Watcher), peu/pas de mid-game. **Smoke and Mirrors** (swap une unité contrôlée et une temporaire → Lillia laisse un sprite ; protège Lillia + draw), Sprite Fountain/Sprite Burst, **Heart of Dark Ice** (sprite à 6 might), **Vilemaw/Valmar**[?] (réaction = clôt la game), Mask of Foresight. Légende = -1 énergie/token par unité temporaire → spam.
- **Rek'Sai (aggro go-wide, Set 2)** : **Immortal Phoenix ×3** (quand tu tues une unité au sort → rejoue du trash ; **se sacrifie elle-même pour reboucler**), **Void Rush** (signature : -2 énergie, proc Legion), Noxus Hopeful (Legion free), Falling Star, **Hidden Blade**, Void Hatchling (scry), Undertitan, Seal of Rage, Rek'Sai Breacher (accelerate). Ruling vu : un **Defy sur Sacrifice** ne sauve PAS l'unité (le sacrifice est un coût → l'unité meurt quand même → proc les 3 Phoenix !).
- Déroulé : Lillia **plus consistante** (double conquer chaque tour, sprites bloquent + tradent volontiers). Rek'Sai = **feast-or-famine** : quand il enchaîne Phoenix/Undertitan = monstre, sinon "tombe à plat" (peine à hold, peu de bodies). G1 & G2 quasi identiques (Smoke and Mirrors T1). G2 : Rek'Sai rate l'**Arena's Greatest** (missed trigger, règle CN) → -1 point gratuit. Lillia ferme via **Vilemaw réaction** (drop sur l'Arena's Greatest, pas de réponse).
- **Verdict** : **Lillia favorisée** (consistance > ceiling de Rek'Sai). `[avis]` design : Set 3 (Lillia) = consistance vs Set 2 (Rek'Sai) = swingy.

## TOP 64 — Garen vs Sivir (miroir Aurora) (Garen gagne 2-1)
- **Garen-Aurora (yellow/orange) = "Aurora-hunter"** `[avis]` : malgré moins de card-draw, **gagne le miroir Aurora** car (1) **Divine Judgment** (stun la légende yellow → mirror-breaker, balancé "comme Twisted Fate"), (2) **Salvage** main-deck (gear-hate + draw), (3) **Harnessed Dragon** (field-removal back-line, trade positif vs les units Aurora), (4) **Kareena**[?] (entre → 3-4 recruits → proc le **passif Garen** sur conquer + cibles de ping Elder), (5) **Unyielding Spirit** main (protège du ping Elder Dragon), Vanguard Armory, **Forge of the Future** (recycle trash→deck + token), Divining Shell (gear yellow scry), Binding Shell, Ash (mini Mind Splitter pour sniper l'Aurora). Build **très light en units** (≈ triple Elder + Kareena + chosen champ).
- Sivir-Aurora : sabotage→gold, Mind Splitter ×3, Elder ×3, Last Rites, Heedless Resurrection, Stack Deck/Scryer's Bloom, **tech "sabotage T1"** (sur Sivir uniquement : pas de counterplay car l'adversaire n'a pas de runes T1, et le gold compense le de-ramp).
- Déroulé : G1 Garen gagne malgré un point-total trompeur (5-1 Sivir) — les casters insistent : **le score ne dit pas qui gagne en miroir Aurora** (c'est qui vide l'autre de ses units/Aurora). **Unyielding Spirit** + double Heedless décident. G2 Sivir high-roll (Aurora on-curve à chaque palier) → stomp. G3 (clock serrée) : **Divine Judgment** stun la légende Sivir → Garen ferme. Ruling : **Repulse ne stoppe PAS Elder Dragon** (Elder ne "select" pas une seule unité).
- **Verdict** : **dans le miroir Aurora, le yellow/orange (Garen/Sivir-yellow) bat le chaos** (removal Order ciblé + gear-hate + recycle). **Garen viable en Unleashed** (grosse surprise). Miroir Aurora = **qui hit l'Elder en dernier / qui prive l'autre de bodies**, pas les points.
