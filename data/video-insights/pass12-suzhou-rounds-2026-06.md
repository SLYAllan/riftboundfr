## R2 — Azir vs Irelia (Azir gagne la game castée)
- **Azir** (Calm+Order, sand soldiers/gear) : la grosse nouveauté Unleashed `[avis]` = **un 2e gear 1-drop** → il est désormais **très consistant de toucher le gear T1** (et avec le gear T1, "c'est un deck complètement différent"). Tech vue : Eye of Herald, **Brutalizer** (+1, +3 si équipé ce tour, déplaçable via **weapon master**), BF Sword, Sacred Shears, Soul Sword (level), **Arise** (signature : un sand soldier par gear + ready 2), Desert's Call, Hidden Blade, Cull the Weak. Plan de fin : cycler les équipements sur les sand soldiers + Arise → double conquer (accelerate Azir Sovereign qui drague tous les soldiers).
- **Irelia** : **Stellacorn Herder** = moteur de draw "qui aurait dû être banni" `[avis]` (a transformé une main de 4 cartes en 8 cartes en 1 tour) ; **Adaptatron en main-deck** (utilisé pour **tuer les gears d'Azir**, ready à action-speed via la légende) ; **Vex Apathetic** = tech anti-Azir clé (**les sand soldiers d'Arise entrent stun → Arise ne peut plus swing** ; +2 might par sort sur Abandoned Hall → pseudo-Irelia) ; Defiant Dance (+2/-2, +3 sur Abandoned Hall), Boots, Star-Crossed, Defy ×2-3, **purple Pike** (Hidden + Backline). Plan `[avis]` : "protect the president" = stick Stellacorn/Irelia, ne jouer QUE des sorts ensuite, draw 15 cartes.
- **Déroulé** : Irelia high-roll (Stellacorn → main monstrueuse), MAIS Azir, qui ne joue **aucun sort défensif** (assumé), développe son board et ferme via cyclage de gear + Arise. Erreur Irelia identifiée : ne pas avoir développé l'Adaptatron en base pour un double-conquer gear-kill propre.
- **Verdict** : matchup serré ; **Vex Apathetic + Adaptatron = le plan anti-Azir d'Irelia** (stun les Arise + détruit les gears), mais Azir gagne par la pression sand-soldiers si Irelia ne stoppe pas Arise. Azir **fort vs Irelia si gear T1**.

## R3 — Ivern vs Master Yi "proving grounds" (1-1 casté ; Yi prend la game longue)
- ⚠️ **Master Yi ici = "proving grounds" (ancien +2 en défense seul), PAS le XP Master Yi Unleashed** (cf. pass4/pass10). Caster `[avis]` : en méta CN, **le Yi mid-range (Scuttle/Rengar) revient PLUS que l'Aurora-Yi** malgré le hype Elder Dragon.
- **Ivern (green)** : champion **Ivern green** (on play/hold : regarde top 3, révèle une unité animal → buff + draw) = **moteur de card-advantage type Grove of the God Willow** ; **Brush token** (+1 aux cats/dogs/birds/poros/Iverns) ; **Friendship** (1 énergie, +1 par tag = jusqu'à +4) > Discipline ; **Bonds of Friendship** (+1 par tag présent = 1-pour-4) ; Mutated Mouser ×2 (tank+shield, défend 4 sur Brush), Nami, Frisky Hunter, Trusty Ramhound, Daring Poro, Exuberant Poro (le Lonely Poro buffé), **Flurry of Feathers** (negate + bird tokens), **Grand Strategem** (tous +5 → birds deflect à 6). **Manipulation de battlefield** : Ivern **retire son propre Brush sur hold** pour réutiliser Star Spring, OU laisse un battlefield disruptif (Rockfall Path anti-ambush, Vilemaw's Lair) à l'adversaire. `[avis]` Ivern **bien plus fort en constructed qu'attendu** (vu faible en pré-release).
- **Master Yi** : Scuttle Crab (+2 = vrai défenseur), **Rengar** (surprise defender), **Vilemaw/Valmar**[?] (réaction = ambush anti-gros, "the Vile Maw harbinger" — finisher), Punch First, On Guard, Discipline, GA, Charm, Star Spring (move-back). Level 6 = ganking + deflect.
- **Déroulé** : G1 Ivern gagne (Yi scoop). G2 Yi gagne la **game longue** (clôt sur **2 Vilemaw**). Multiples **blunders Yi** : oublie le **reveal du Scuttle Crab** (hand knowledge) ET **son propre +2 passif** (calcul de might faux, corrigé par le juge).
- **Verdict** : matchup jouable des deux côtés ; **Ivern = engine de card-advantage + Friendship** qui out-grind ; Yi mid-range gagne s'il tient un battlefield (+2) + Vilemaw finisher.

## R4 — Kha'Zix vs Irelia (Kha'Zix gagne 2-0)
- **Kha'Zix** (le nouveau jungler ambush Unleashed, purple/orange) : chosen champion **dans la zone** = menace permanente à 4 énergie (comme Rengar). **Combo signature anti-Irelia** : **Irresistible Faefolk** (move → drague une unité ennemie sur le battlefield) **+ Forbidding Waste** (battlefield : -2 might au défenseur seul) → rend **Irelia défenseur seul à -2**, puis **ambush Kha'Zix** dedans = kill ("gank Irelia into the next dimension"). Tech : Demacian Diplomat (XP), **Qiyana**[?] (deflect, conquer → draw/channel), **Grim Resolve** (+3 + 2 XP si win), Punch First, **Void Assault** (signature : move une alliée puis une ennemie → isole + déplace pour gagner le combat), Nidalee, Edge of Night (hidden +2), Vex, **Akshan** (SB anti-gear : vole les Boots), Ride the Wind, First Mate.
- **Irelia** : joue **Irelia Fervent SANS protection** (ni GA ni Zhonya's) → **punie** par Faefolk+Forbidding Waste+ambush ; **Repulse** (counterspell ciblant ses propres unités, anti-Defiant-Dance adverse... ici anti-Kha'Zix), Defiant Dance, Boots, Star-Crossed, Stellacorn. **Perma-de-ramp** : Irelia vit sur des "war runes" (3 runes/tour) plusieurs tours → étranglée.
- **Ruling vu** : sur un battlefield **où Kha'Zix ambush en réaction au "when I defend" trigger**, le **défenseur** garde la priorité → peut Tide-Turner AVANT (timing defender-first). Vex Apathetic : pas besoin de contrôler le battlefield (stun même en attaquant) → **pas d'ambush défensif possible vs Vex**.
- **Verdict** : **Kha'Zix favori vs Irelia** `[avis]` via **Faefolk + Forbidding Waste** (isole/affaiblit Irelia) + ambush + chosen-champion-zone permanent. ⚠️ **Nuance vs pass4** (où Kha'Zix = "faible vs hold/Irelia") : **contre Irelia spécifiquement (peu d'unités), le plan drag-isolate inverse le matchup**. Irelia doit sortir sa championne **protégée** seulement.

## R5 — Ezreal vs Fiora (Ezreal gagne 2-0)
- **Ezreal control** = la version la plus **oppressante vue du tournoi** `[avis]` : **3 Bewitching Spirit + Pack of Wonders + Treasure Trove** → **vide entièrement la main adverse** ("1re fois qu'on voit toute la main éliminée") + Treasure Trove = "ne manque jamais de cartes". Removal Wages of Pain / Bellows Breath / Eclipse / Stupefy ; **Star-Crossed** + Fizz (rejoue) ; **Vex Apathetic** (stun le Trophy Hunter ambush de Fiora). Battlefield **Frozen Fortress** (1 dmg/début de tour → met les unités dans la range des Eclipse/Bellows).
- **Fiora** ici = **mid-range, champion Fiora Victorious (PAS Worthy)** ; **whiff le Baited Hook les 2 games** → trop lente. Rift Herald, Harnessed Dragon, Sea Monkey, Kinkou Monk, Call to Glory, Trophy Hunter, Watcher+Bellows.
- **Verdict** : **Ezreal favori** vs Fiora-mid-range (mill de main + removal). `[avis]` Ezreal = top 3-5 de la méta, sous-représenté car les joueurs chassent d'abord les best-of Set 3.

## R6 — Poppy (Aurora) vs Fiora (Poppy gagne 2-0)
- **Poppy = Aurora yellow** : Sigil of the Storm, Dazzling Aurora, **Elder Dragon** (hardcast aussi), Rift Herald (engine de draw/filtre), **Harnessed Dragon** (field removal), **Forge of the Future / "Future of the Fluff"**[?] (unité 1-drop = points early + récup du trash + cible de Shadows Call + anti-Fizz), Confront, **Shadows Call** (donne temporary → draw), Vanguard Armory, Ash/Akshan, Ruination. Légende Poppy = hold → 1 XP ; à 3 XP → draw 1 (légère mais pas vanilla).
- **Clé `[avis]`** : Poppy **joue très bien SANS Aurora** (Forge of the Future = points early type Gust, Elder Dragon roll-cast, Rift Herald) → **"un bon joueur Aurora = ce qu'il fait quand il ne trouve PAS l'Aurora"**. Bonus yellow : **unités 8-coût-1-power** → joue un Herald à 8 runes PUIS Aurora le tour suivant.
- **Fiora Victorious** sabote l'Aurora on-curve (×2) mais Poppy stabilise via Elder Dragon hardcast + double Harnessed Dragon. (Pilote Fiora = l'expert Fiora OG d'Origins/Spiritforged.)
- **Verdict** : **Poppy-Aurora étonnamment résiliente** ; Fiora-mid-range manque de pression. Couplage pass5 : Poppy = top C "Aurora jaune sans dig" — ici elle surperforme via le plan-B sans-Aurora.

## R7 — LeBlanc vs Fiora (Fiora gagne 2-1)
- **LeBlanc (yellow)** : Karthus (double les death-knells), **Echo** (reset les runes payées pour accelerate → ×2 = tours combo greedy), reflections (signature Mirror Image), **Glasc Mixologist** (rejoue ≤3 might), Black Rose Dignitary (T1 going 2nd), **Vi Peacekeeper** (ambush + stun, "jamais faux en order deck"), Watcher, Ruined Rex, Soaring Scout, Hidden Blade.
- **Fiora (Victorious)** : **Challenge = LA carte anti-LeBlanc `[avis]`** → tue le **Karthus dès T2 gratis**, AVANT que les reflections snowball (vu décisif les 3 games) ; **Nidalee** (draw on win, "MVP meta-read" anti-tokens) ; **Italy**[?] (= "Draven" unit, draw on combat win — Fiora manque de draw) ; **triple Salvage** (anti-BF Sword) ; **Repulse** (counter, body devient une couleur premium Set 3) ; Punch First ×3, Singularity, BF Sword/Doran's Blade, Set Brawler.
- **Déroulé** : G1 Fiora (Challenge ×2 sur Karthus). G2 LeBlanc (Winswept Hillock + double Glasc Mixologist snowball). G3 (Aspirant's Climb par LeBlanc pour gagner du temps de setup) : Fiora ferme, partiellement décidé par une **mauvaise gestion du chrono** (LeBlanc n'a pas donné le "turn zero" à Fiora en overtime).
- **Verdict** : **Fiora favorisée vs LeBlanc SI Challenge online tôt** (déni du moteur Karthus/death-knell) ; LeBlanc snowball si Karthus colle. `[avis]` body = couleur premium Set 3 (Repulse).

## ⭐ Méta-takeaway global (outro R7, `[avis]`)
- **Méta Sydney = la plus diverse jamais vue en TCG** : LeBlanc n°1 à **seulement 6-7 %** ; chaque légende a son petit pocket. **Aucun deck n'a un matchup favorable across-the-board** = signe de méta saine (Set 3 a ajouté assez d'outils ; bans Set 2 ont nettoyé).
- **Master Yi #1 dans le cœur de la Chine, Fiora #2** (beaucoup de Baited Hook Fiora copiés des joueurs EDG).
- **Fiora boostée par Set 3** : le draw (sacrifice, Shadows Call temporary, **Kinkou Initiate**) corrige son point faible historique (peu de draw).
