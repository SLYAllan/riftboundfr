## VEX (Unleashed) — contrôle "chaos", tenir un battlefield
- **Légende** : pioche 1 à chaque fois que tu **tiens** un battlefield (snowball à la Grove of the God Willow).
- **Chosen champion** : 3 options — Vex Mocking (shield/tank, se déplace vers unités stun, angle proactif) ; Vex Cheerless (vu en méta Spiritforged : réduit les sorts action/réaction + restreint les sorts adverses) ; **Vex Apathetic** = reco `[avis]`. Apathetic stun chaque unité que l'adversaire pose + l'empêche de bouger tant qu'elle est au battlefield + Deflect → hold quasi incontestable, très bon marché on-curve.
- **Plan** : T1 unité qui atteint un battlefield (**Mutated Mouser** efficace). T2 = tour-clé (combien tu commit, combien de runes laissées pour actions/réactions, quoi cacher). Mid : renforcer + poser Vex (Sona, cartes cachées, sorts de réaction). Late : verrouiller le scoring adverse (**Alpha Wildclaw**[?] protège le board, **Tianna Crownguard**[?] empêche l'adversaire de finir) ; tours à 2 pts via **Emperor's Divide**.
- **Battlefields** : Bandle Tree (renforce le hold via cartes cachées sans dépenser de runes), **Grove of the God Willow** (Draw 1 on hold ≈ Draw 2), Ravenbloom Conservatory (going-first, punit les petits trades, synergie Charm/Evelynn), Star Spring (utilité des unités cachées : retreat).
- **Cartes-clés** : unités 2-énergie (Evelynn, Teemo, Tide Turner[?], Mutated Mouser, Overzealous Fan) ; **Sona** (ready 4 runes en fin de tour → développe en ton tour tout en gardant des runes pour le tour adverse ; le Draw de Vex compense sa faim de cartes) ; **Tiana[?] + Ahri** = solvent le retard en tempo de points (Ahri gagne des points, Tiana[?] empêche l'adversaire de scorer) ; contres : Defy, Not So Fast, Hard Bargain, Abandon ; Back Off (main = pioche, caché = stun), Switcheroo (réponse aux grosses unités), Existential Dread (stun répétable à 2 énergie).
- **Matchups** : meilleurs `[avis]` vs **Lillia** et **Ornn** (leurs tokens sprites entrent stun + ne bougent pas via Apathetic → disparaissent avant de menacer). Punit les autres decks de hold (Massie[?], certains LeBlanc). **Difficile vs Aurora** (jeu lent → leur late-game / Elder Dragon qui assigne les dégâts létaux individuellement dévaste un board concentré). Vulnérable aux **boardwipes** : Unchecked Power, Ruination, Downwell → anticiper, ne pas surcommit.

## KHA'ZIX (Unleashed) — "Void Reaver", mouvement / isolation
- **Légende (Void Reaver)** : gagne un combat → 1 XP ; dépense 1 XP (exhaust) buff une unité ; dépense 2 XP (exhaust) déplace une unité alliée exhaustée d'un battlefield vers sa base. Domaine **Body + Chaos**.
- **Principe** : garder les unités à la base, les ramener après chaque attaque, re-attaquer avec des combat tricks (action speed). Tout ce qui reste sur un battlefield sans trick = mort. Isoler et tuer en 1v1.
- **Chosen champion** : **Kha'Zix Mutating Horror** = reco `[avis]` (Ambush, jouable en réaction sur un battlefield où tu as des unités ; à l'attaque/défense si une unité ennemie est seule ici → +2 might ce tour + 2 XP). Alt : Kha'Zix Evolving Hunter (Hunt ; à l'attaque dépense 3 XP = inflige des dégâts égaux à son might à une unité ennemie ici) — situationnel/cher mais avec Punch First peut infliger 10.
- **Plan** : T2 combo cassé = **Irresistible Faefolk** (déplace une unité vers un battlefield + drag une unité ennemie dedans) puis ambush Mutating Horror = kill + 3 XP (un des meilleurs T2 du jeu). Mr. Root (move to battlefield → 2 XP). Grim Resolve (pump + XP). Mid : Kha'Zix + Nidalee + Qiyana[?] farment les triggers de conquer puis reviennent à la base ; Void Assault + Ride the Wind. Late `[avis]` build perso : XP sur Evolving Hunter pour détruire des battlefields + **Yone Bladesman** (empêche l'adversaire de retreat à la base → nulle part n'est safe).
- **Battlefields** : Monastery of Hirana (conquer → dépense un buff pour draw 1), Sunken Temple (conquer avec unités mighty → 1 énergie draw 1), **Star Spring** = favori (combo Fae Folk : drag ennemi, ambush, renvoie le Fae Folk à la base).
- **Cartes-clés** : Irresistible Faefolk, Mr. Root, Insightful Investigator (révèle la main + défausse ciblée façon Mindsplitter), Nidalee (Ambush, win combat → draw 1), Qiyana[?] (conquer → draw 1 ou channel 1 rune), Fizz (rejoue un sort du trash ≤3 énergie en l'ignorant → réutilise Void Assault). Sorts : Punch First (+5 might), Grim Resolve (+3 might, win combat → 2 XP), **Void Assault** (signature : déplace une alliée puis une ennemie).
- **Matchups** : **faible vs decks de hold** (Ivern, Vex) — ils campent un battlefield trop fort, tu ne peux pas casser (seule issue Void Assault / Fae Hook, dur si counterspells / purple Vex). Even/bons vs mid-range (Ornn[?], XP Master Yi, Rek'Sai — skirmish fun).

## RENGAR (Unleashed) — Fury+Body, ambush / "pounce"
- **Légende (Rengar Pridestalker)** : quand tu joues une unité, donne +1 might à une unité ce tour. Domaine **Fury + Body**.
- **Chosen champion** : **Rengar Trophy Hunter** = reco `[avis]` (Ambush, jouable en réaction sur un battlefield où tu as des unités, **et** peut ambush vers un battlefield avec unités ennemies même si tu n'y as aucune unité ; 5 énergie + 1 recycle orange, 6 might +1 légende = +7 might surprise au tour adverse). Alt : Rengar Unseen (Accelerate, Assault 2, Deflect, Ganking — 4 might, 1 recycle rouge) ; Rengar Pouncing (Reaction, Assault 2, jouable sur un battlefield que tu attaques).
- **Plan** : T1 Irresistible Faefolk ou **Fresh Beans** (gear, draw). T2 (going first) : drag ennemi via Fae Folk, kill avec ambush (Rengar Pouncing ou Nidalee → win combat = draw). Combo via **Star Spring** (drag + ambush + renvoie le Fae Folk à la base, conquer safe + draw + kill). Mid : Kai'Sa Survivor, Noxus Hopeful (might + draw), First Mate, empile le might. Late `[avis]` cheese : **Thrill of the Hunt** (signature) + **Brynhir Thundersong** = conquer librement, force les cartes adverses, puis Frill au tour adverse → l'adversaire ne joue pas de cartes 2 tours d'affilée. Punch First + Challenge pour finir / casser les holds.
- **Battlefields** : Star Spring (1er battlefield), Treasure Horde (conquer → 1 énergie joue un Gold Gate token exhausté), Empress Dice[?] (conquer → 1 énergie rend une unité à la main + joue un token Sand Soldier 2 might).
- **Cartes-clés** : Irresistible Faefolk (must-have), Grim Apothecary (return unité à la main, Ambush — protège tes grosses unités), Nidalee, Kai'Sa Survivor (draw rouge), Brynhir Thundersong. Sorts : **Repulse** (counterspell cheap ciblant TES unités, excellent vs rebuke), Unyielding Spirit (punit un tour entier si bien timé), Punch First, **Challenge** (nécessaire vs Vex pour tuer une unité inatteignable), Thrill of the Hunt. Gear : Fresh Beans.
- **Matchups** : galère/even vs decks de removal (**Jhin, Kai'Sa, LeBlanc**) — trop dépendant des unités, tuées on cooldown. **Plus gros contre = Vex** (tout deck purple) → prier pour un Challenge sinon cuit.
- Réf décklist citée : Guangzhou City Challenge (1re place).

## XP MASTER YI (Wuju Master, Unleashed) — Calm+Body, level/XP
> ⚠️ **Désambiguïsation** : il s'agit du **Wuju Master** (build XP/level), PAS du Wuju Bladesman (cf. [[feedback_master_yi_disambiguation]]).
- **Légende (Wuju Master)** : niveau 6 = +1 might à TOUTES tes unités (permanent) ; niveau 11 = toutes tes unités entrent **ready**. Domaines **Calm + Body**.
- **Chosen champion** : Master Yi Meditative (faible, à ignorer) ; Master Yi Honed (ganking + enter ready, 7 énergie 1 power, flexible) ; Master Yi Unstoppable (discount aux niveaux 3/6/11 ; niveau 16 = untargetable ; avec le +1 du niveau 6 entre à **13 might** = plus grosse unité du jeu) ; **Master Yi Tempered** = reco `[avis]` (pas de coût power, **Hunt 2** = 2 XP on conquer/hold → atteint vite les paliers ; niveau 6 → ganking + deflect).
- **Plan** : early = farm XP via Master Yi + cartes hunt, sans jouer dans la removal adverse (règle d'or : rester safe). Mid : accumuler ressources, préparer les grosses unités. Dès niveau 11 (tout entre ready) → gros swings de tempo. Endgame : Master Yi Unstoppable, Elder Dragon, White Flame Protector.
- **Battlefields** : Gardens of Becoming (tap tes unités ici → XP), **Reckoner's Arena** (les triggers de Hunt comptent sur conquer ET hold → double le Hunt chaque tour), Aspirant's Climb (hold → les 2 joueurs channel des runes → ramp vers les cartes chères).
- **Cartes-clés** : Master Yi Tempered, **Voracious Gromp** (Hunt 3 → t'amène seul aux hauts paliers, surtout sur Reckoner's Arena), Elder Dragon (removal, entre ready au niv 11), White Flame Protector (+8 might sur lui-même ; au niv 11 = push de 17 might ; combo Not So Fast), Arachnid Horror (jouable sur les battlefields adverses si unité seule, Hunt 2), Master Yi Unstoppable. Sorts : **Alpha Strike** (nouvelle signature : removal + XP), **Concentrate** (nouveau : pioche cheap, solve le card draw), Discipline (staple set 1, buff might en réaction).
- **Matchups** : galère vs decks qui punissent le départ lent, surtout **Vex** (demande une réponse early). Bon vs decks combo qui set up lentement (**Irelia, Aurora** → plein de surprises late-game).
- Réfs décklists citées : 4e place sur 128 joueurs en Chine (mid-range, puissance T2-T4) ; 4e place tournoi Runes&Rift (ramp, Anivia + Elder Dragon).

## PYKE (Unleashed) — Fury+Chaos, aggro-control sorts / disruption de main
- **Légende (Pyke Blood Harbor Ripper)** : paye 1 énergie (tap la légende) → rend une unité d'un battlefield à ta main, puis joue un Gold Gear exhausté (sauve des unités on-effect à rejouer + ramp un peu de power). Domaine **Fury + Chaos**.
- **Chosen champion** : Pyke Returned (3 énergie 3 might, Hidden + Backline, tue une unité en combat → Gold Gear exhausté/tour ; T1 solide going second, n'abîme pas l'éco de runes) ; **Pyke Dockside Butcher** = reco `[avis]` (variant Fury, 2 might, accélérable pour 1 power → +2 might ; Hidden + **Ganking** = plus fort que Backline ; play accéléré 3 énergie 1 power surprise 4 might + gank/conquer).
- **Plan** : attaquer la **main** adverse (Bewitching Spirit + Mindsplitter), gagner l'attrition en tuant les unités-clés au sort, finir sur un Baron. T1-2 : scoring via unités 2-énergie, puis discard via Bewitching Spirit ; sinon kill pour ralentir le scoring adverse. Utiliser la légende pour garder les unités en main (le gold paie les sorts moins cher). Mid : ramp + Star-Crossed/Fizz (rejoue Star-Crossed) + Mindsplitter. Late : **Baron Nashor** (buff toutes les petites unités) + signature **Death from Below** (kill, rejouable si la cible ≤3 might). Déplacer le Baron via Ride the Wind (rejouable au Fizz).
- **Battlefields** : **Ripper's Bay** (génère une rune exhaustée quand tu rends une unité à ta main pour 1 énergie → ramp vers Baron ; going first), Void Gate (neutre, boost dégâts de sorts ; game 1), Vilemaw's Lair[?] (going second, lock des unités ennemies pour Death from Below ; utile vs movement decks Irelia/Kha'Zix).
- **Cartes-clés** : Windsinger (2-énergie défensif/offensif), Fizz Trickster (value sur sorts ≤3 énergie), Bewitching Spirit (discard, combo avec Gust/Buke[?] quand l'adversaire est à 1 carte), Baron Nashor (finisher). Sorts : Falling Star (removal n'importe où), Star-Crossed (rebounce ton Fizz/Bewitching ou un gros pour rejouer), Switcheroo, Gust (disruption + protège tes petites unités), Rebuke (ne peut pas être Defied, garder mid/late), **Death from Below** (signature).
- **Matchups** : durs vs **aggro** (Lillia, Annie) sauf action-speed (Gust, Void Seeker). Vs green (Vex, Ivern) : pousser + vider la main, bait les Defy avant un Death from Below sur leur Sona/champion Ivern. Vs **Aurora** : hand disruption + Mindsplitter pour arracher l'Aurora de la main. Builds plus aggro possibles via Kai'Sa Survivor + Darius.

## IVERN (Unleashed) — Calm+Order, "brush" / animaux (tags), hold
> Whisper dit "Ivan" = **Ivern** ; "Friend to Wall" = **Friend to All**.
- **Légende** : sur conquer/hold, exhaust la légende pour **remplacer un battlefield par un token Brush**. Le Brush donne +1 might à tous les cats/dogs/poros/birds et aux unités Ivern (1re fois qu'on voit remplacer un battlefield). → deck qui joue beaucoup d'unités pour maximiser le Brush.
- **Chosen champion** : **Ivern Friend to All** (épique Order, 6/6 ; on play choisis bird/cat/dog/poro et gagne ce tag ; sur conquer/hold score +1 pt si les 4 tags sont sur le board ; combo Reckoner's Arena = 2 triggers ; bon en tempo vs decks lents) ; **Ivern Nurture** (Calm, 5 énergie 1 power, ultime 4 ; on play et sur hold regarde top 3, révèle une unité bird/cat/dog/poro → buff une unité alliée, trouve aussi les non-animaux comme Daisy ; plus consistant, top pour matchups lents). Les deux jouables selon l'objectif.
- **Plan** : early diversifier les tags (Stalwart Poro, Mutated Mouser, Trusty Ramhound), prendre un battlefield → Brush → s'installer. Mid : Ivern Nurture (renforce + ajoute des unités gratis), Arch-Soft Poro[?] (sprout des birds). Late : agressif (Daisy 8 might cheap + stun, Stalking Wolf, Deathgrip) ou hold (Alpha Wildclaw + Friend to All accélère les points). Counters : Defy, Not So Fast, **Flurry of Feathers**.
- **Battlefields** : adaptés à la légende. Hold → Rovi[?] (draws, going first). 2 écoles : (a) battlefields "when I conquer" (Treasure Hoard gold, Zaun Warrens draw, Candlelit Sanctuary scry 2) qu'on conquer puis transforme en Brush ; (b) battlefields disruptifs qu'on neutralise en Brush (Vilemaw's Lair stop move-to-base, Paper Tree, Sigil of the Storm de-ramp, Frozen Fortress 1 dmg).
- **Cartes-clés** : Mutated Mouser (tank shield, défend pour 4 sur Brush), Arch-Soft Poro[?] (5/5, tap → 2 tokens Bird 1 might/deflect, 2 might sur Brush), Stalking Wolf (4 énergie 1 power, 6 might, Ambush en tuant un bird/cat/dog/poro), **Daisy** (unité signature, 9 énergie -1 par tag unique → jusqu'à 5 énergie, entre ready, on attack stun si 4 tags), **Friendship** (1 énergie réaction, +1 par tag unique = jusqu'à +4, must-include).
- **Matchups** : shine vs decks qui peinent à conquer / peu d'unités (**Viktor**) — le Brush donne un hold énorme. Even vs Aurora et autres hold decks (dice roll décisif). **Galère** vs effets qui touchent tout le board sans cibler / tout le battlefield → **blue decks (Kai'Sa, Jhin)** : The Watcher, Unchecked Power, sorts de dégâts (mitigé par Alpha Wildclaw / Not So Fast si drawn).

## REK'SAI (Spiritforged) — Fury+Order, control, jouer depuis le deck
- **Légende (Void Burrower)** : sur conquer, exhaust → révèle top 2 du deck, joue-en 1, recycle le reste. Domaine **Fury + Order** (sorts de dégâts/kill, unités accélérées, effets Legion).
- **Archétype recommandé** = **Control** `[avis]`. Pièce maîtresse : **Immortal Phoenix** (quand tu tues une unité ennemie au sort → paie 1 énergie + 1 Fury rune pour le rejouer du trash → unité quasi permanente, peu d'unités nécessaires). Économie : **Seal of Rage** (gear, donne 1 Fury power en réaction → paie les sorts Fury + le retour du Phoenix).
- **Chosen champion** : **Rek'Sai Breacher** (Accelerate 1 énergie 1 Fury power, Assault 1 ; les unités alliées jouées d'ailleurs que la main ont Accelerate). Combo gear **Sun Disc** (effet Legion : après avoir joué une carte, exhaust → prochaine unité entre ready).
- **Plan** : conquer → regarde top 2 (légende), joue une carte utile. Booster via signature **Void Rush** (révèle top 2, banish/joue 1 -2 énergie, draw l'autre — démarrer le deck avec 3). Combo **Candlelit Sanctum** (regarde top 2 AVANT la légende → plus de cartes à filtrer + proc les Legion comme Noxus Hopeful gratuitement). Opener fort going first : recycle 1 Fury rune → Seal of Rage → Noxus Hopeful pour 2 énergie. Early : unité 2-énergie + Seal of Rage, Noxus Hopeful + Phoenix, scorer easy (death-knell rend de la value). Late : Phoenix + combos sorts rattrapent les points.
- **Battlefields** : Candlelit Sanctum (scry avant la légende), Zaun Warrens (conquer → discard 1 draw 1 ; peut défausser un Phoenix à rejouer), Veiled Temple (boost les Rage shields/Sun Discs).
- **Sorts** : Cull the Weak (chacun tue une unité), Void Seeker (4 dmg + draw), Falling Star (3 dmg ×2), Piercing Light (2 dmg ici + 2 ailleurs), Hidden Blade (Hidden, kill au battlefield + controller draw 2), Vengeance, Salvage (kill un gear + draw, sideboard anti-gear), **Void Rush** (signature). Units : Soaring Scout (death-knell channel 1 rune), Honest Broker (death-knell Gold Gear), Noxus Hopeful (Legion -2 énergie), Immortal Phoenix.
- **Matchups** : **bon** vs Fiora & Lucian (beaucoup de sorts vs leurs unités + thermo beam[?] anti-gear). Sivir & **Irelia** durs mais jouables (Sivir sabote des sorts → contrôler le board early ; Irelia = mass counterspells, all-in quand elle manque de runes). **Très durs** : Draven & Ezreal (mass card draw, t'out-resource ; Ferrous Forerunner + accelerate + Last Rites rejouent leurs unités).

## LILLIA (Unleashed) — Calm+Mind, tempo sprites/tokens
- **Légende (Thousand-Tailed Watcher)** : 4 énergie + tap → joue un token Sprite ready avec keyword temporaire, -1 énergie par autre unité temporaire alliée. Domaine **Calm + Mind**. Deck **tempo** pur (vitesse > puissance) : on ne tient pas les battlefields, on se bat dessus chaque tour, pression via sprites buffés.
- **Chosen champion** : Lilia Protector of Dreams (5 énergie 4 might, donne Tank aux tokens, +1 might quand tu joues un token — `[avis]` un peu lackluster actuellement) ; **Lillia, Fae Fawn** = reco `[avis]` (3 énergie 3 might, Accelerate → T1 going second ou conquer T2 going first ; après s'être déplacée laisse un token Sprite 3 might exhausté).
- **Plan** : atteindre **6 points** au plus vite (puis menace de lethal). Spawn de tokens (légende + autres) → support (gears/sorts) → finisher. T1 : unité 2-énergie (Scuttle Crab, Ravenbloom Student) ou **Sprite Fountain** (≈2 pts garantis going first). Support : gears Heart of Dark Ice, Mask of Foresight (conquer + hold à 4 might). Buffs : Surge[?]/Discipline. Finisher : **Thousand-Tailed Watcher** (≥2 en deck) + **Sprite Burst** (5 énergie, burst accéléré, non-Defiable → menace les 2 battlefields). Combo : Lillia, Fae Fawn + **Smoke and Mirrors** (caché, en réaction sur un push → bouge 2 unités temporaires, Lilia laisse un token en bougeant → défends avec deux tokens 3 might + draw).
- **Battlefields** : **Dusk Rose Lab**[?] (game 1 ; au début du tour tue une unité à toi ici + draw 1 → tes sprites meurent de toute façon → draw "gratuit"), Seat of Power (going second, draw), Black Flame Altar (going second alt si assez de draw), **Targon's Peak** (going first reco ; conquer garanti T2 via sprite accéléré).
- **Cartes-clés** : Scuttle Crab (draw), Ravenbloom Student (profite des sorts cheap), Lillia, Fae Fawn, Thousand-Tailed Watcher, Disarming Rake (sideboard vs Aurora/Hookdex[?], non-sabotable). Gears : Sprite Fountain, Mask of Foresight, Heart of Dark Ice (sprite à 6 might/tour). Sorts : Charm, Discipline, Defy (×3), Sprite Burst, Singularity (anti unités moyennes en base), Unchecked Power (vs Vex hold / Baron Nashor), **Lilting Lullaby** (signature : stop les sorts adverses ce tour).
- **Matchups** : **bon** vs spell-heavy (Pyke, Jhin) — peu d'action-speed pour ralentir tes conquers. Hold decks (Ivern, LeBlanc) durs une fois installés (peper de sprites + Watcher/Unchecked Power). **Pires** : aggro-hold (Draven, Vex) et surtout **Vex Apathetic** (annule le gameplan → débat ouvert : Crescent Strike vs plus d'unités, les deux abîment l'archétype).

## LEBLANC (Unleashed) — Mind+Order, "reflections" temporaires + death-knell
- **Légende (LeBlanc Deceiver)** : sur conquer/hold, défausse une carte → joue un **token Reflection temporaire** d'une unité présente. La Reflection copie les valeurs/abilities imprimées MAIS pas l'effet "on-play". Temporaire → disparaît au début du tour → on favorise les unités à **death-knell** pour la value (répétable avec Karthus Eternal).
- **Chosen champion** : **LeBlanc, Everywhere At Once** (épique, 4/4 sans power ; tes cartes temporaires ne se déclenchent PAS à son battlefield → les Reflections restent plus longtemps ; keyword **Backline** ; se duplique sur conquer/hold ; pour decks go-wide / présence persistante) ; **LeBlanc Fragmented** (3 énergie 1 power, 3 might, Soul 1, death-knell draw 1 / draw 2 si elle meurt en beginning phase — entre dans le deck même si pas chosen champion ; safe pour decks conquer/death-knell).
- **Plan** : early unités à death-knell à copier (T1 Soren Scout[?], T2 move + Reflection pour tempo/2e point via Windswept Hillock gank ou Star Spring). Mid : **Glasc Mixologist** (core, death-knell rejoue une unité ≤3 might : LeBlanc Fragmented, Karthus, Soren Scout) + **Karthus Eternal** (fait trigger les death-knells une fois de plus, stacke). Late : Mirror Image (signature), The Watcher, accélération pour les points finaux.
- **Battlefields** : Dostro's Lab[?] (beginning phase tue une unité alliée ici → draw 1 ; avec LeBlanc Fragmented = +3 cartes/tour — attention au miroir / vs Lillia), **Windswept Hillock** (la plus forte : 1 unité conquer 2 battlefields/tour, la Reflection ready gank en face), Star Spring (move gratuit de la Reflection vers l'autre battlefield), Arena's Greatest (point gratuit, going first dans les métas lentes).
- **Cartes-clés** : Soren Scout[?] (death-knell channel rune), Watchful Sentry (death-knell draw), **Karthus Eternal**, **Glasc Mixologist**, Baited Hook (cash les Reflections mourantes pour cheat une grosse unité), **Mirror Image** (signature : copie une unité alliée/ennemie, 3 énergie 2 power → hors range de Fire, joue autour de Not So Fast en ciblant les tiennes), Sacrifice / Nhi the Leashed[?] (kill une unité ≥5 might pour de la value).
- **Matchups** : **très bon spread** `[avis]`. Cauchemar pour le contrôle / spell-damage rouge (Kai'Sa, Jhin) — tuer ses unités = leur donner la value (draw/channel/unité gratuite), pas d'attrition possible. Aurora galère (tempo 2 pts/tour). **Galère** vs hold decks (Massie[?]) — manipulation de hold/mouvement + Cull the Weak/Hidden Blade jaunes cheap. Vs **Vex Apathetic** (stun les Reflections jouées ce tour → réduit légende + signature) : jouer créatif.

## DIANA (Unleashed) — Mind+Chaos, mid-range/skirmish "showdown"
- **Légende (Scorn of the Moon)** : en réaction, ajoute 1 énergie utilisable **uniquement en showdown** → plus de runes pendant les combats.
- **Chosen champion** : **Diana Lunari** = reco `[avis]` (3 énergie 3 might, sans power ; au début d'un showdown ici paye 1 → predict, révèle le top deck, si c'est un sort draw-le → card draw à 1 énergie + scry ; T1 going second). Alt : Diana No Longer Human (4 énergie 1 chaos power, 3 might, Ambush, +2 might quand tu joues un sort — fort en attaque mais fragile en défense après avoir dépensé ses sorts).
- **Plan** : se battre en showdown avec des sorts forts, prendre l'avance early, finir sur des unités mid-range. Early : unités 2-énergie + Diana Lunari, sorts Stupefy/Gust/Eclipse/**Moonfall** (signature : charm une unité vers un battlefield + -2 might à toutes les unités ennemies là → clear early). Mid : **Hwei** (Hwei brooding painter[?] : à chaque move draw 1 puis discard 1 → unité discardée = +3 might, gear = ready 2 runes, sort = redraw ; combo Ride the Wind, rejouable au Fizz). Late : Moonfall sur gros battlefields, Star-Crossed/Rebuke en défense, accélérer un Thousand-Tailed Watcher.
- **Battlefields** : Ravenbloom Conservatory (game 1, draw vers les sorts), Abandoned Hall (nouveau, Ravenbloom Student / Diana No Longer Human montent énormément avec les sorts de combat ; going second), Targon's Peak (going first, garde des runes ouvertes pour défendre).
- **Cartes-clés** : Ravenbloom Student (scale avec les sorts cheap + Abandoned Hall), Diana Lunari, **Hwei**[?], Tide Turner (2-énergie, safe + redraw), Fizz Trickster. Sorts : **Moonfall** (signature), Stupefy, Star-Crossed (renvoie une unité en base / sauve / rejouable au Fizz), Eclipse (-4 might sans power, pas de minimum 1, + scry), Ride the Wind (score vite / counter push / combo Hwei jusqu'à 14 might).
- **Matchups** : forte vs decks lents / qui peinent à suivre son skirmish (**Poppy, nouveau Master Yi, Kha'Zix**). Even vs **Lillia** (hyper-aggro ; stabiliser + Star-Crossed, attention à Lilting Lullaby). **Durs** : decks de sorts de dégâts (**Pyke, Ezreal, Jhin**) — seule protection = Hard Bargain ; ne pas jouer dans Falling Star (1 seule unité à la fois).

## VI (Unleashed) — Fury+Order, aggro "excess damage" / équipement
- **Légende** : ready une unité quand tu infliges **3+ dégâts en excès** → chaque attaque surdimensionnée snowball (conquer un battlefield, ready, gank l'autre → finir à 6 pts de nulle part).
- **Chosen champion** : **Vi Destructive** = reco `[avis]` (recycle des cartes du trash → gros boost de might + ganking natif → finit les games) ; Vi Hot-Headed (paye énergie+power pour **doubler son might** à répétition, Deflect mais pas de ganking → brute-force les holds) ; Vi Peacekeeper (Order, Ambush + stun on attack, builds réactifs). Reco = un des deux Fury.
- **Plan** : early **parité de points** (ne pas racer bêtement) + poser des unités efficaces (Unsung Hero, Pouty Poro — jetables, gênantes à retirer, portent les gears). Les gears se ré-équipent quand l'unité meurt → corps jetables qui portent l'équipement puis transfert sur de meilleures unités. Mid : unités équipées + légende = swings de tempo (ready partout → tours à 2 pts ou fuite) ; Kai'Sa Survivor (draw). Late : créer un attaquant énorme, wipe un battlefield en excess damage, convertir sur l'autre via ganking. (Combo démo : Rek'Sai[?] + Deathgrip transfèrent ~22-29 might sur une Vi ready → wipe + gank pour finir, le tout pour 9 énergie.)
- **Battlefields** : Sunken Temple (draw en récompense des gros swings), Arena's Greatest (accélère), Vilemaw's Lair (trap les unités ennemies), Windswept Hillock (sweep + récompense le might).
- **Cartes-clés** : les Vi (closers), Rek'Sai[?] (menace de fin de game), Kai'Sa Survivor (draw via conquer répété), Darius Trifarian (closer + repositionnement/mouvement), Pyke[?] (unité gank cheap 4 might ready). Sorts : **Sacrifice** (draw 2 + channel), Hidden Blade (removal + synergie unités jetables), **Deathgrip** (draw 1 + redistribue d'énormes quantités de might en réutilisant l'équipement). Gear : **Hextech Gauntlets** (signature, souvent ~1 énergie 1 power voire 0), BF Sword (+3).
- **Matchups** : bon vs decks lents et vs autres aggros qui peinent face aux unités sur-équipées. **Aurora = bon matchup** (tes unités deviennent assez grosses, tu outpace avant qu'ils stabilisent). **Vex difficile** (hold fort) mais **faible early** → mettre la pression T1-2 avant que les stuns dominent. **Plus grosse faiblesse = gear removal** (Salvage, thermal beam[?]).

## JHIN (Unleashed) — Fury+Mind, ramp "4 sorts" / removal
- **Légende (Jhin Virtuoso)** : quand tu joues un sort en dépensant **4+ énergie**, tu peux le banish ; quand 4 sorts sont banish avec lui → mets-les au trash, **channel 4 runes (NON exhaustées — une première) + draw 1** → ramp + tempo énorme.
- **Chosen champion** : **Jhin Murderous Artist** (4 énergie 1 power, 4 might, ganking + deflect ; **on move : +1 énergie +1 power** → curve up, caste un sort autrement injouable ; garder en champion zone pour un mid-game fort) + **Jhin Meticulous Killer** (4 might pour énergie seule ; predict ; jouable pour **1 mind power sans coût énergie** si tu as joué un sort 4+ ce tour → 4 might T2 après une removal ; en mettre 3 et le jouer de la main).
- **Plan** : activer la légende puis spiraler avec runes + gros sorts + unités mid-range. Early : développer sans risque (peu d'action-speed → ne pas scorer si pas de protection), removal qui touche la base + active la légende (Deadly Flourish, Rocket Barrage) ; fillers de draw / "compteur de 4" (Downstage Dramatics, Consult the Past). Mid : board d'unités cheap (Noxus Hopeful, Jhin Meticulous Killer), protéger via Frigid Touch / Stupefy. Late : Thousand-Tailed Watcher + Sprite Burst (≥4 énergie) ; Unchecked Power vs gros holds (Baron Nashor). Standout : **Singularity** (reach, active la légende, retire 2 unités où qu'elles soient).
- **Battlefields** : Void Gate (game 1 neutre, boost dégâts de sorts), Forgotten Library (control → predict quand tu dépenses full énergie sur un sort ; going first), Vilemaw's Lair (going second, trap pour Piercing Light / signature ; utile vs movement Irelia/Kha'Zix).
- **Cartes-clés** : Plundering Poro (2-énergie value early), Jhin Meticulous Killer (×3), Thousand-Tailed Watcher, Kai'Sa Survivor. Sorts : **Curtain Call** (signature toolbox : 4 abilities + repeat, value max = kill une unité ≤6 might au battlefield via -4 & 2 dmg + kill une ≤3 might en base + draw), Rocket Barrage (removal + anti-gear : Dazzling Aurora, Vanguard Armoury), Singularity (×3), Deadly Flourish (removal + gold), Frigid Touch (skirmish showdown + active la légende), Sprite Burst, Progress Day (×2).
- **Faiblesses/matchups** : les sorts 4-coût peuvent quand même être **Defied** (et un sort Defied n'active pas la légende) ; attention Hard Bargain + Repulse (laisser 2 énergie de marge vs légende chaos). **Fort** vs decks qui développent un board mid-range (**Rengar, Diana, Draven** — tu kill tout). Even vs decks qui ripostent (Ezreal) ou Aurora (Poppy, Miss Fortune — danger si tu n'as pas la gear removal). **Galère** vs green/deflect (**Vex, nouveau Master Yi** — Defy/Not So Fast cassants ; kill le chosen champion Master Yi tôt avant qu'il scale l'XP).

## ARCHÉTYPE AURORA — autour du gear **Dazzling Aurora** (⚠️ PAS une légende)
> **"Aurora" = un archétype, pas une Légende.** C'est un **gear** (Dazzling Aurora, 9 énergie 2 power) autour
> duquel on construit le deck ; n'importe quelle Légende **body domain** peut le porter (Miss Fortune, Sivir, Master Yi…).
> Dans les matchups des autres fiches, "vs Aurora" = vs un deck Dazzling Aurora, peu importe la Légende qui le pilote.
- **Carte** : en fin de tour, révèle le deck jusqu'à une unité, banish + **joue-la en ignorant son coût**, recycle le reste. → deck rempli d'unités **très haut might** sorties gratis en boucle (Elder Dragon, Baron Nashor, Mindsplitter). High-roll : monstrueux si trouvé on-curve, peut bricker sinon.
- **Légende porteuse** : n'importe quel **body domain**, mais hiérarchie `[avis]` : **Miss Fortune** = reco (Chaos+Body ; légende donne ganking → **Baron untargetable** qui stomp ; signature **Bullet Time** wipe un battlefield ; combo Drake) ; **Sivir** (mêmes domaines, meilleure éco de runes via gold tokens + Sigil of the Storm → **supérieure en miroir**) ; **Master Yi** (Calm+Body, le plus **consistant** sans voir l'Aurora ; Zhonya's protège un Elder, Desert's Call = 2 sand soldiers early).
- **Plan** : early ramp + recherche d'Aurora (Mobilize, Catalyst of Aeons ; Stacked Deck, Lunar Boon, Scry...). Gust pour ralentir/bounce le 2-drop adverse. Mid : viser l'Aurora ; combo MF Champion (ready runes/légende/unité) ; **Mindsplitter** de la main (games 2-3) pour retirer la gear-hate AVANT de poser l'Aurora. Late : protéger + wipe (Bullet Time, Flurry of Blades + Elder Dragon ; Repulse, Headless Resurrection). Trick anti-sabotage via MF (float + ready une rune pour atteindre 9 énergie).
- **Battlefields** : Aspirant's Climb (+1 tour de jeu, going second vs aggro), Vilemaw's Lair (trap, MF gank pour ne pas rester coincé), Rockfall Path (sécurité vs ambush Ornn[?]/Vilemaw, going first vs hold), Sigil of the Storm (de-ramp l'adversaire), The Forgotten Monument (l'adversaire ne score pas avant son 3e tour ; going first vs aggro/sprites).

Unités (peu) : **Elder Dragon** (assigne les dégâts létaux individuellement = tout le monde à 1 HP → wipe board entier, combo Flurry of Blades), Baron Nashor (situationnel, stacke pour le sortir en dernier), Mindsplitter.
- **Matchups** : **faible** vs super-aggro (**Lillia, LeBlanc**) si ramp manqué, et vs **order domain** (Hidden Blade, **Cull the Weak** — marche sur le Baron car ne le cible pas), Salvage (gear-hate + draw). **Bon** vs hold decks (Master Yi, Kingpin[?]) qui mettent du temps à set up. Miroir = **pur gamble** (le dernier à hit l'Elder Drake gagne) → **Sivir favorisée** (éco de runes).
