## "Vex is OVERRATED" (Podcast #2)
- **Thèse Kachuzzi + accord du panel `[avis]`** : Vex très fort mais **A, pas S** (peut-être S une fois la méta installée). Faiblesses : **s'effondre si le hold tombe**, n'accumule pas bien les ressources, veut développer sur le battlefield (vulnérable). (Cohérent pass5/6/7 : "overrated", 0 top 8 Vancouver.)
- Tier list chinoise (vote 1600 joueurs) : **Vex S** (le panel conteste), LeBlanc top, Kha'Zix top-A (uniquement via Aurora), Jhin bas (panel : "pas si mauvais, red+blue"), Poppy B.
- **Anti-LeBlanc** `[avis]` : **bouncer, pas tuer** (death-knells) → **Rebuke** + **Star-Crossed** (depuis le ruling "triggers payés à l'activation", LeBlanc doit tap+discard pour faire son token → ne peut plus le faire à l'infini) ; **le discard devient un staple anti-LeBlanc**. Variantes LeBlanc : Riptide Rex ×3 (wipe), sentries+yellow draw, big-Poro tokens, Glasc+Karthus.
- **Anti-Vex** : **Stare Down**[?] (déplace toutes les unités de might inférieur hors du battlefield) cité comme contre. Vs Rengar : Vex Apathetic stoppe l'ambush.
- **Pyke underrated** `[avis]` (Overzealous Fan, scoring + bounce, échappe aux sorts de dégâts, bon vs LeBlanc via discard).
- **Lillia polarisante** `[avis]` : auto-win certains matchups / ne fait rien dans d'autres ; la légende **wipe ton board en début de tour** → Jibs/Kachuzzi la classent C/faible.
- **Fiora a resurgi** `[avis]` : méta redevenue tempo (où Fiora brillait en Chine) ; a perdu le matchup vs Miraiko[?] (banni = bon) mais doit jouer Casino[?] (draw) au lieu du battlefield de draw perdu.
- **Kai'Sa = S tier** `[avis]` (Jibs a gagné un LAN Londres : bat MF Aurora en quart + Fiora en finale). Tech : **Ravenborn Tome** (draw non-action, atteint des breakpoints de dégâts), triple Forerunner + 1 Darius, **pas de Cleaves**, sideboard de 1-of "spicy" (anti-clunky).
- **MF Aurora = meilleur/le + consistant Aurora** `[avis]` ; nouveaux outils Set 3 : **Scryer's Bloom** (gear, scry 2 → 1) + le 3-énergie discard-1-draw-2 (Lunar Boon : discard un Elder → Last Rites → rejoue via Aurora). Master Yi peut-être meilleur Aurora en Set 3.

## Rulings (importants — couplage pass6/7)
- **Origine de la règle 702** (incident Pentastag à Bologna) : adversaire a fait des erreurs **irréparables de zone face-cachée** (Singularity pas mise au trash), mais les juges n'avaient **pas l'outil "game loss"** (seulement warnings/DQ ; warnings reset/jour ; 3 même catégorie = game loss). Lui a coûté un **top 64 en jour 2**. Son post Reddit/Twitter → **Riot a changé les règles : un juge peut upgrade un warning en game loss ; règle 702 = info de zone face-cachée, si modifiée irréparablement = game loss.** (déjà en mémoire via cross-set-casts ; ceci en est l'origine).
- **Symbol of the Solari**[?] = carte **devenue blanche/inutile** : elle agissait "si un combat finit en **égalité**" → les **égalités ont été retirées** du jeu (résultats = win / loss / **no contest**, plus de "tie") → la carte ne fait plus rien. (Bon exemple de carte cassée par un changement de règles.)
- **Contrôle de battlefield** : **tant qu'il y a quelque chose sur la chain, le contrôle d'un battlefield ne peut pas changer** → (a) **fixe** le combo Lillia/Rengar "conquérir au tour adverse" (flash sur le même battlefield + Ride the Wind = supprimé) ; (b) permet le combo **Glasc Mixologist / Zhonya's + Lonely Poro** (en showdown tu gardes le contrôle → tu peux replay sur le battlefield / bounce le Zhonya's au death-knell sans le gâcher).
- **Ride the Wind sur un battlefield** = tu es **attaquant** (résout avant le showdown), à la différence d'un drag/Blitzcrank (où tu es défenseur). Mais un défenseur **non-propriétaire** peut quand même scorer un point de conquête défensive.
- **Legion = confus** `[avis]` : la section Legion dit qu'il s'applique si "finalisé" (peu importe le counter) ; les règles de jeu disent que la carte doit être **jouée** → contradiction ; ajout de "handle outstanding tasks / finalize" censé aider mais flou.
