**Conversion jour 2** : **LeBlanc 33,3 %** (26 joueurs, + haut taux MAIS meilleur classement seulement 39e — punie en rounds profonds par Yi/Diana), Master Yi 31 % (Utrecht ~36 % / win-rate ~60 %), Annie 29 %, Ezreal 26,2 % (Bradykin top 8).

**Top 8** : **1er Factor (Master Yi)** — tech **Fiora Peerless** (défend 1v1 = double son might → imbattable seule, combo On Guard/Discipline), **Emperor's Dais** (ruling clarifié : refuser de payer l'énergie → pas de token mais bounce l'unité pour réabuser l'on-play), Arena's Greatest (Yi devenu agressif, game finie T4) ; 2e BS White (Diana aggro, 9 two-drops, Arena's Greatest, seulement 2 Hwei) ; 3e Bradykin (Ezreal control, The List + Deadly Flourish + Frozen Fortress) ; 4e Ninsanity (Diana, tech **Eager Apprentice** = mini-Vex, Rockfall Path) ; 5e Diana (Evans Shrim) ; **6e Ralivia (Lux loop)** ⚠️ deck combo infini via carte **Echo** = "glitch" non-intentionnel, **candidat ban** unanime du panel (existe aussi en version Echo+Jhin) ; 7e Prismatism (Annie, 6e fois) ; 8e Pyke control (Miru — falling star/void seeker, gear anti-Rune Runner, Aspirant's Climb sans Baron).

## RQ Vancouver (plus gros regional à date, ~2000 joueurs)
**Meta jour 1** : **Irelia 130 (top, ~12 %)**, LeBlanc & Diana 5-6 %, MF/Sivir/Azir 4-5 %, Master Yi, **Ezreal seulement 46 (3 %)** (les bons joueurs sont passés sur Diana, "le nouveau jouet"), Jhin 33 (> Kai'Sa !, 1 seul en J2), **Ivern 19 (= Draven 19), 1re DST d'Ivern** (best-of par Boulevard).
**Conversion jour 2** : **Irelia 32,6 %** (142 joueurs → 42 en J2, n°1 ; record reste Draven ~38 % à Bologna), **Draven 31,6 %** (6 joueurs, ~5 à 7-1 en J1), Annie 29,2 %, **Kha'Zix 28,2 %** (surprise, Z-Rob 10-2), Master Yi 26,4 %, MF 23 % / Sivir 17 %.

**Top 8** : **1er AlanZQ (Diana)** — **2e titre regional (après Bologna) = double champion** ; liste ~90 % identique à la Diana 2e d'un regional chinois ; tech **2 Acceptable Losses + Turn to Dust en main** (action-speed, tue les GA/Boots d'Irelia instantanément), 2 Fizz, seulement 2 Moonfall main, 3 Gust (respect LeBlanc), 2 Baron Nashor SB ; 2e **Sam (Rengar)** — tempo très rapide, tech **Determined Sentry** (1-might refund, proxy battlefield + proc Pridestalker), 12 two/one-drops, 1 seul Rengar (finit à 6 pts avant d'en abuser), Kai'Sa + Darius accelerate ; 3e Houses (Master Yi, Seat of Power + Emperor's Dais, 10 cartes de buff) ; 4e Diwali (Diana, 3 Frigid Jewel) ; 5e Rockclo (Azir, Arena's Greatest, 1 Death Grip seulement) ; 6e Areto (Aurelia[?], purple Pyke hidden) ; 7e Ali "swaggy Yolo 420" (Sivir Aurora, tech **Harrowing + Annie + Headless Resurrection** = boucle Elder Dragon) ; 8e BaoBao (Irelia standard, 2e Irelia maindeck).

## Méta-takeaways transversaux (couplage pass3-6)
- **Trajectoire méta Set 3** : Aurora (peur initiale) → le terrain s'adapte (sideboards moitié anti-Aurora, gear-hate maindeck) → montée d'**Irelia / Diana / Master Yi** (decks "consistants, plan linéaire"). **Diana gagne Vancouver, Irelia gagne Sydney, Master Yi gagne Hartford.**
- **Vex** : fort mais **gagne/perd au tour 2** → 0 top 8 à Vancouver. Confirme le `[avis]` "overrated" de pass5. **Vex Apathetic = carte floodgate ban-watch n°1.**
- **Gust** : redevenu n°1 (Vancouver 41 %) après un creux Hartford — corrèle avec le retour des decks à 2-3 drops (fin de l'ère Draven) et l'anti-LeBlanc. **Defy** = sort le + joué (contre 70-75 % des sorts).
- **Scuttle Crab + Vex Apathetic + Tide Turner** = trio d'unités structurant le green/purple. **Star Spring + Emperor's Dais + Arena's Greatest** = battlefields clés (mouvement / abus on-play / aggro).
- **Lux loop (Echo)** = combo infini non-intentionnel → **candidat ban** (à surveiller pour la liste de bans, cf. `src/lib/banned-cards.ts`).
- **Confirme la mémoire** : Hartford = Factor (Master Yi) champion ; Vancouver = **AlanZQ (Diana) double champion**.
